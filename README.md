# Cube Music

**Cube Music** 是一个放在浏览器里的音乐盒：点亮格子，它就会一圈一圈地循环演奏。

不用安装任何东西，打开网页就能玩。

## 在线试玩

**[harukiinharu.github.io/cube-music](https://harukiinharu.github.io/cube-music/)**　——　原版

**[harukiinharu.github.io/cube-music/large.html](https://harukiinharu.github.io/cube-music/large.html)**　——　大面板

两版用同一套引擎，只是网格规格不同：

| | 原版 | 大面板 |
|---|---|---|
| 网格 | 16 步 × 16 音 | 64 步 × 48 音 |
| 音阶 | D 大调五声 | 半音阶 —— 相邻行差一个半音，像吉他每格一品 |
| 音域 | A6 → A3（3 个八度） | A7 → A#3（47 个半音，将近 4 个八度） |
| 一圈 | 2 秒 @120BPM | 8 秒 @120BPM |
| 方块 | 26px | 26px —— 跟原版一样大 |

大盘面的棋盘是原版的 12 倍面积（2048 × 1536）。**屏幕够大就整块显示、一格都不用滚；
装不下就在棋盘框内滚动**，页头和控件不会跟着滚走。方块大小因此和原版完全一致，
不会被缩水。

**单步时长两版完全一样**，所以大面板变长的是段落，不是音符的快慢。
大面板的音阶是原版五声的**超集**：原版每个音都能在新面板里找到，
只是行号变了，所以要照搬图案得重新数格子。

## 怎么玩

| 你做的操作 | 会发生什么 |
|---|---|
| 左键点一下某个格子 | 打开 / 关掉这个音符 |
| 按住左键拖动 | 连续涂一片 |
| 右键某个格子 | 单独听一下这个音 |
| 空格 | 播放 / 暂停 |
| **拖棋盘上方那条标尺** | **把播放游标挪到任意一列**（点一下跳过去，按住拖就是擦洗） |
| **⌘Z**（Windows 上 Ctrl+Z） | 撤销。**一次拖动算一步**，不会退成十几步 |
| **⌘⇧Z**（或 Ctrl+Y） | 反撤销 |
| **Alt + 拖动** | 拉出一个框，选中一片格子（会高亮成青色） |
| **在选中的框里按住左键拖** | 整块搬走 |
| **A** / **X** | 把选中的这一块填满 / 清空 |
| **Esc** | 取消选中 |
| 「清空」按钮 | 全部擦掉（这一步也能撤销回来） |
| 「谱子」按钮 | 展开保存面板，代码会跟着谱子实时更新，也可以粘贴别人的代码载入 |

打开页面时只会**启用声音**，不会自己放起来 —— 想听按空格或点「播放」。

## 保存与分享

**你不用手动保存** —— 每改一下就自动存在浏览器本地，刷新或关掉重开都还在。
两个面板各存各的，互不覆盖。

想把谱子发给别人、或者换台机器接着弹，点「谱子」：

- **复制** 得到一段短代码（比如 `CM2.AbCd...`），发给对方
- 对方点「谱子」，把代码粘进输入框，点 **载入** 就能听到一模一样的谱子

代码存的是**音高**而不是「第几行」，所以**换个面板也照样能载** —— 以后大面板再加
音域、或者换个音阶，旧代码都还对得上。跨面板载入时，本面板没有的音高会自动
就近对齐到最接近的音，超出宽度的时间步会被丢掉，界面上会如实告诉你各有多少个。

顺带一个好处：只记有音符的位置，所以代码很短。大面板 64×48 上，
旧写法固定 512 个字符，现在十个音符只要 50 个字符。

下方还有几样可以调的：

- **速度** —— 循环有多快（40 ~ 240 BPM）
- **音量** —— 声音大小
- **涟漪** —— 点亮格子时那一圈会发光的波纹，不喜欢可以关掉
- **播放列** —— 一条淡淡的竖线，标记现在循环到哪一列

## 它是怎么发声的

16 列就是一小节里的 16 步，从左到右循环播放；从上到下则是从 A6 到 A3 的一串
D 大调五声音阶。因为只用五个音，所以**随手乱点也不会难听** —— 把几个格子摆成
某种形状，往往就是一个好听的琶音。

大面板干脆换成了**半音阶**：48 行从 A7 一路排到 A#3，相邻行只差一个半音，
跟吉他每格一品一样。这样什么调都能弹，但也意味着**随手乱点会很难听** ——
五声音阶那个「怎么点都好听」的魔法没有了，得自己动耳朵挑音。

## 关于

- 灵感来自 [【warma实况】Cube Music](https://www.bilibili.com/video/BV1as411q7ax)
- 由 **DeepSeek v4.1 Flash** 重构实现
- 原型是 2009 年 Hobnox AudioTool 里的 **ToneMatrix** —— 一个 Flash 音乐玩具。
  这里用原生 JavaScript + Canvas + Web Audio 把它重写了一遍：
  无框架、无构建、无依赖，整个项目就是一个网页

## 本地运行

把仓库下载下来，双击 `index.html`（或 `large.html`）就能玩，仅此而已。
